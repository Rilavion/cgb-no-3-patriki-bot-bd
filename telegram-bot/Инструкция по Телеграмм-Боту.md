# Telegram-уведомления ЦГБ №3 — запуск с PostgreSQL

Telegram-воркер работает отдельно от сайта: читает очередь уведомлений из автономной PostgreSQL и отправляет сообщения в зарегистрированные темы частной Telegram-группы. Supabase, Vault и браузерный доступ к токену не используются.

## Что требуется

- Python 3.11 или новее;
- доступ к PostgreSQL с хоста воркера;
- токен Telegram-бота;
- исходящие HTTPS-соединения к `api.telegram.org` либо HTTP(S)-прокси.

## Установка

```bash
sudo useradd --system --home /opt/cgb-telegram-bot --shell /usr/sbin/nologin cgbtelegram
sudo mkdir -p /opt/cgb-telegram-bot
sudo cp telegram_worker.py requirements.txt /opt/cgb-telegram-bot/
sudo python3 -m venv /opt/cgb-telegram-bot/.venv
sudo /opt/cgb-telegram-bot/.venv/bin/pip install -r /opt/cgb-telegram-bot/requirements.txt
sudo chown -R cgbtelegram:cgbtelegram /opt/cgb-telegram-bot
```

Создайте `/etc/cgb-telegram-bot.env` с правами `600`:

```dotenv
DATABASE_URL=postgresql://cgb_telegram:PASSWORD@DB_HOST:5432/cgb?sslmode=require
TELEGRAM_BOT_TOKEN=1234567890:replace_me
CGB_SITE_URL=https://cgb3patriki.ru
TIMEZONE=Asia/Irkutsk
TELEGRAM_POLL_SECONDS=4
# OUTBOUND_PROXY_URL=http://user:password@proxy.example.org:3128
```

Затем установите службу:

```bash
sudo cp cgb-telegram.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now cgb-telegram
sudo systemctl status cgb-telegram
sudo journalctl -u cgb-telegram -n 100 --no-pager
```

## Подключение тем

1. Добавьте бота администратором в частную группу с включёнными темами.
2. В каждой теме отправьте `/register Название темы`.
3. На сайте откройте настройки Telegram, назначьте зарегистрированную тему каждому маршруту и включите отправку.
4. Команда `/status` проверяет состояние, `/chatid` показывает ID группы и темы.

Маршруты: экзамены, повышения, электронные заявления/восстановления, увольнения, отпуск IC/OOC и отгулы.

## Безопасность и диагностика

- Не храните рабочий `.env` и токен в GitHub.
- Пользователю БД воркера достаточно прав на таблицы `telegram_settings`, `telegram_topics`, `telegram_notifications` и `telegram_bot_status`.
- При сетевой ошибке сначала проверьте доступ к Telegram. Если провайдер блокирует соединение, задайте `OUTBOUND_PROXY_URL`.
- При ошибке таблиц примените `postgres-migration/01-schema.sql` к целевой базе.
