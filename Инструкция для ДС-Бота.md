# Быстрый запуск Discord-бота с PostgreSQL

## Требования

- Node.js 20 LTS или новее;
- исходящий доступ к Discord;
- сетевой доступ к PostgreSQL;
- уже применённый `01-schema.sql` и импортированные данные.

## Установка

```bash
npm ci --omit=dev
cp .env.example .env
chmod 600 .env
npm start
```

В `.env` заполните `DISCORD_TOKEN`, `GUILD_ID`, два ID каналов и строку `DATABASE_URL`. Рабочий `.env` в GitHub не загружается.

Пример строки с TLS:

```dotenv
DATABASE_URL=postgresql://cgb_bot:PASSWORD@DB_HOST:5432/cgb
PGSSL=require
```

## systemd

```ini
[Unit]
Description=CGB 3 Discord bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=cgbbot
Group=cgbbot
WorkingDirectory=/opt/cgb-discord-bot
EnvironmentFile=/opt/cgb-discord-bot/.env
ExecStart=/usr/bin/node /opt/cgb-discord-bot/index.js
Restart=always
RestartSec=5
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

После запуска проверьте `journalctl -u cgb-discord-bot -n 100 --no-pager`. Бот должен войти в Discord, обновить `bot_status` и синхронизировать роли/участников.
